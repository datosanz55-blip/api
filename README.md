# Центр медицины «АПИ» — редизайн сайта

Новая главная страница для [api-centre.ru](https://api-centre.ru/): тёмная «медовая» тема, крупная типографика, соты и пчёлы.

Контент (направления, цифры, цены, контакты, отзывы, программы НИИ) взят с текущего сайта клиники.

## Структура

```
index.html            — страница
assets/css/style.css  — стили
assets/js/main.js     — меню, анимации, счётчики, карусель отзывов, форма
assets/img/           — изображения
```

Сборка не нужна — это статический сайт. Локальный просмотр:

```
python3 -m http.server 8000
```

## Что важно знать

- **Форма записи** не отправляет данные на сервер (у статической страницы его нет): после проверки полей она открывает WhatsApp клиники с заполненным текстом заявки. Чтобы заявки приходили на почту или в CRM, нужен обработчик на сервере.
- **Ссылки «Подробнее»** у направлений ведут на соответствующие страницы текущего сайта api-centre.ru.
- **Фотографии** пчёл, мёда и пасеки — с Unsplash (лицензия Unsplash разрешает коммерческое использование без указания авторства). Обложка книги `book-ms.jpg` — с сайта клиники. Пчёлы, соты и логотип нарисованы в SVG.
- Цены и цифры перенесены как есть; перед запуском их стоит сверить с клиникой.
